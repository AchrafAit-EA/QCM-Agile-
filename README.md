# 🧠 QCM Module 202 — Approche Agile

Application web interactive dédiée à la **révision et à l’évaluation des connaissances** du Module 202 : **Approche Agile — Partie 1**.

L’application propose un QCM de **20 questions** couvrant les principaux concepts de la gestion de projet, de la matrice RACI, des méthodes prédictives et des approches Agiles.

## 🎯 Objectif

Permettre à l’étudiant de :

* réviser les notions essentielles du module ;
* s’entraîner avec une correction immédiate ;
* réaliser un examen blanc dans des conditions chronométrées ;
* identifier ses erreurs et comprendre les corrections ;
* refaire uniquement les questions auxquelles il a répondu incorrectement.

## ⚙️ Fonctionnalités

### 📚 Deux modes de fonctionnement

**Mode Entraînement**

* Correction immédiate après chaque réponse.
* Affichage de l’explication pédagogique.
* Indication des bonnes et mauvaises réponses.
* Score mis à jour en temps réel.
* Signal sonore lors de la sélection d’une réponse.

**Mode Examen**

* Les bonnes réponses ne sont pas révélées pendant le test.
* Calcul du résultat à la fin de la session.
* Affichage du bilan complet des réponses.

### ⏱️ Gestion du temps

L’utilisateur peut choisir entre :

* **20 minutes**
* **15 minutes**
* **Temps illimité**

Le test est automatiquement finalisé lorsque le temps disponible est écoulé.

### 🧭 Navigation et progression

* Barre de progression.
* Navigation entre les questions.
* Grille permettant d’accéder directement à une question.
* Compteur des questions répondues.
* Possibilité de **marquer une question pour la relecture**.

### 📊 Résultats et analyse

À la fin du QCM, l’application affiche :

* le score obtenu ;
* le pourcentage de réussite ;
* le nombre de réponses correctes ;
* le nombre d’erreurs ;
* le temps consacré au test.

Les résultats peuvent être filtrés par :

* **Toutes les questions**
* **Réponses incorrectes**
* **Réponses correctes**

Chaque question dispose d’une **correction détaillée et d’une explication pédagogique**.

### 🔄 Révision ciblée

Après le test, l’utilisateur peut :

* refaire l’ensemble des 20 questions ;
* refaire uniquement les questions auxquelles il a répondu incorrectement.

### 🖨️ Impression des résultats

Les résultats peuvent être imprimés ou enregistrés au format PDF grâce à la fonction d’impression du navigateur.

## 📖 Notions abordées

Le QCM couvre notamment :

* Définition et caractéristiques d’un projet
* Les éléments essentiels d’un projet
* Cahier des charges
* Charte de projet
* Maître d’Ouvrage (MOA) et Maître d’Œuvre (MOE)
* Ressources d’un projet
* Livrables
* Parties prenantes internes et externes
* Rôles dans un projet informatique
* Matrice RACI
* Contraintes de projet
* Méthode en Cascade (Waterfall)
* Cycle en V
* Effet Tunnel
* Cycle en Y / 2TUP
* Manifeste Agile
* Différences entre Cycle en V et Approche Agile
* Scrum et Kanban

## 🛠️ Technologies utilisées

* **HTML5** — structure de l’application
* **CSS3** — personnalisation et animations
* **JavaScript** — logique du QCM et gestion des interactions
* **Tailwind CSS** — conception de l’interface responsive
* **Font Awesome** — icônes
* **Google Fonts — Inter** — typographie
* **Web Audio API** — signaux sonores
* **Canvas Confetti** — animation de célébration des résultats

## ✨ Interface

L’application dispose d’une interface responsive avec :

* tableau de bord des questions ;
* indicateurs de progression ;
* système de couleurs pour différencier les états ;
* fenêtres de confirmation ;
* animations d’apparition ;
* affichage adapté aux différentes tailles d’écran.
